## Contenido

Codificación en Python, con interfaz gráfica de usuario en Tkinter, de los siguientes ejercicios del libro *Ejercicios de programación orientada a objetos con Java y UML* de Leonardo Bermón Angarita:

- Ejercicio 8.2 - Notas (promedio, desviación estándar, mayor y menor nota)
- Ejercicio 8.3 - Figuras (volumen y superficie de cilindro, esfera y pirámide)

## Ejecución

Los programas abren ventanas de escritorio, por lo que deben ejecutarse localmente:

```
python actividad3_ej82_notas.py
python actividad3_ej83_figuras.py
```
